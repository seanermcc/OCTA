# Next CNV training round — after collection

The target remains complete native en-face CNV footprints, with fewer false detections far from lesions while retaining real CNVs. This release trains no model. Its frozen queue offers 253 eligible acquisitions across 10 non-WT animals; it does not guarantee 30 of them contain CNV. At delivery there are no human v7 confirmations. The live status can be refreshed with `summarize.py`.

1. **Freeze and audit a versioned dataset after collection.** Use source identities and hashes from the refreshed history/precedence reports, then independently validate native source/grid, mask bounds, completion signatures/revisions and disjoint targets. Combine eligible original/v5 evidence, applicable explicit v6 human masks and completed v7 fields. Valid v7 whole-field confirmation supersedes older evidence on that exact acquisition. A v7 draft blocks automatic fallback until adjudicated; never silently union conflicting sources. V6 ratings and original predictions are not masks. Partial historical labels may supply valid confirmed positives, never unmarked negative coverage. Completed v7 positives supply reviewed background outside positive/ignored areas; confirmed No-CNV fields supply whole-field negatives. Drafts and deferrals remain ineligible for v7 whole-field export. Preserve uncertainty and explicitly ignored conflicts. Lack of thickness does not make tissue CNV-negative or invalidate a confidently drawn lesion.

2. **Count acquisitions, animals and repeated lesions separately.** Thirty confirmed positive images is a collection milestone, not 30 lesions or independent subjects. Preserve all useful negative fields encountered; roughly 10–15 varied negative images is a provisional useful addition for false-positive control, not a completion requirement, fixed prevalence or sufficiency guarantee. Track session/eye/repeat relationships; do not transfer masks across repeat acquisitions without validated registration. The random queue spans 10 animals, but actual positive coverage determines what splits are feasible. TS169/TS283 offer only one eligible visit each. Day estimates and TS336 discrepancies must remain visible in analysis.

3. **Group development and assessment by animal.** Keep an animal's eyes, visits, repeats, crops and augmentations in one fold/role, assigning roles before patch extraction. With actual label coverage, either set aside assessment animals before model selection or use animal-excluded development folds. Labeling an animal now does not force its use for fitting. Do not call TS267 an unseen CNV test animal when initializing from a TS267-trained checkpoint. Assessment results repeatedly inspected to guide changes become development evidence. A genuinely unseen final test may require new animals; never choose it based on model performance.

4. **Audit upstream exposure as well.** The current automatic ALL_LABELLED thickness-producing layer models saw existing cohort animals. A CNV-only animal holdout is therefore not end-to-end independence. Use animal-excluded upstream providers or genuinely new animals for that stronger claim. Otherwise report exactly the restricted independence tested, including checkpoint ancestry and all upstream inputs. Keep the present within-TS267 v6 evidence separate from cross-animal assessment.

5. **Keep inputs autonomous and aligned.** Use numerical structural OCT and actual OCTA, with frozen automatic availability/shadow and numerical thickness where appropriate. Never feed manual footprints, correction locations, human unreliability, GUI colors/text, source/animal/eye/day identity or target-derived distances. The OCTA channel is a saved-retinal-crop projection, not a layer slab. Use the exact acquisition/grid/orientation and pixel dimensions. Full retina is ILM to outer RPE edge; photoreceptor composite includes ONL. Preserve measurement NaNs in saved products; only model tensors use neutral normalized fill, paired with availability. Fit normalization on training animals and valid values only. Do not substitute the v5 human-influenced display thickness for autonomous v6 inputs.

6. **Run a bounded matched comparison.** Keep image-only A and thickness-assisted C with matched animal splits, sampling, augmentation and training budgets. Compare against frozen v6 outputs on the same completed fields; do not overwrite them. Add B or availability/shadow ablations only if evidence warrants. Treat random initialization versus fine-tuning as an explicit experiment, tracking checkpoint ancestry. More model complexity is not the default response to sparse single-animal supervision. Preserve native full-field scores, thresholds, all components and configuration; do not introduce arbitrary circularity, size or lesion-count caps.

7. **Target false positives using reviewed evidence.** Balance training sampling across acquisitions/animals and include reviewed background/negative fields rich in vessels, shadows, bright structures and field edges. Mine hard negative patches only inside human-confirmed development negative coverage. A model-only detection is not a negative label. Retain ordinary representative cases. Inspect full-field behavior and recall/precision curves rather than tile Dice alone. Choose thresholds/checkpoints only with development validation; assessment labels cannot tune thresholds or postprocessing.

8. **Prespecify useful measurements.** Report missed lesions, false CNV regions per completed image and recall/precision tradeoffs, footprint Dice/IoU, border error within reviewed areas, count/area errors, negative-field false-positive behavior, observed correction burden and focused review time. Freeze one-to-one lesion matching (for example IoU ≥0.1 with 0.25/0.5 sensitivity analyses) before scoring; detection matching is not outline accuracy. Explicitly handle ignored and partially ignored objects. Empty-vs-empty negatives do not contribute perfect Dice to inflate positive overlap; report their predicted area/components separately. Stratify by animal, stage and artifact context; use animal-clustered summaries/uncertainty and report sample counts. Random eligible-post-D7 sampling and developer-selected examples do not establish natural cohort prevalence. Review time is an audit aid, not proof of careful attention.

9. **Train in documented rounds.** Freeze dataset/model revisions and reproducible evaluation protocols, never retrain after each stroke. Compare practical gains as new animals/fields are added; use measured errors and learning curves if 30 positives are inadequate. If persistent errors require axial relationships lost in en-face projections, test a B-scan-stack/2.5D extension later with suitable supervision and a matched budget. The GUI's full-depth bands are only lateral footprint context and must never become an invented axial lesion-volume target.

Existing verified v6 evidence comprises nine compact 2D U-Nets trained within TS267, with B/C predictions on 324 acquisitions. Mean holdout Dice A/B/C was 0.678/0.584/0.733 across seeds on repeated later-visit entries from that animal. C is promising, but that result does not establish performance on new animals or guarantee that the next round will improve. The release history records all prior scope and exposure limitations.

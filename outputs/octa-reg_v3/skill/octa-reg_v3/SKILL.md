# octa-reg_v3

Work in `G:/OCT_TreeShrew/octa`. Read `AGENTS.md`, `README.md` and `PIPELINE.md` before changing the pipeline. Source lives in `code/octa_reg_v3`; release and reviewer are in `outputs/octa-reg_v3`. Earlier registration and CNV releases are read-only inputs.

## Input and review contracts

- Isolate animal number and eye. Native x=A-line, y=B-scan, 512² at approximately 1460/512 µm. Do not infer anatomical NSEW, reflect images, change pixel scale or reconstruct RAW.
- `inputs.freeze()` verifies v1 prepared-source provenance and v9 version-bound decisions. Latest manual corrections take priority; only kept regions contribute, with uncertain pixels masked. Whole-field confirmed corrections/manual targets and confirmed model masks have greater weight than partial corrections or predictions. Unchecked reviews never mean no-CNV. Preserve explicit source exclusions.
- `inputs/manifest.json` freezes source hashes and placement review snapshots. Current TS165 OD revision 81 and OS revision 61 contain 20 individually confirmed placements, seven flagged, and no whole-montage confirmation. Preserve their exact poses/categories and OD manual ONH. Never manufacture a new human confirmation or edit original labels.
- New v3 edits live in each eye's `human_review.json` and immutable history. Inherited approval is explicitly attributed to its original revision. Do not rebuild an already reviewed baseline in place.

## Search and interpretation

Run multiscale feature matching and local rigid trials; inspect small-vessel support, structural/detail correlation, spatial spread, ONH consistency and graph alternatives separately. CNV location is supporting evidence and cannot certify a vessel-poor match. Lower cross-date CNV weight; do not demand identical lesion shapes across dates.

The TS165 comparison requires matching the reference coordinate frame before computing discrepancies. OD improved in the development run but OS did not consistently improve. This is not independent accuracy. Large changes from v2 require manual review; propagate uncertainty through flagged bridges and refit the final supported backbone without flagged observations. Retain uncertain or unlocalized fields instead of inventing precise anatomy.

Run registration, cohort, v3 search and persistence tests. Verify all 324 inventory records, 19 eye groups, source hashes, rigid inverses, no excluded transforms, exact inherited reviews and all completed/failed groups. Inspect representative maps and the browser, testing writes only on isolated fixtures. Save trial counts, alternatives, code hashes and limitations.

## Reviewer and downstream analysis

Default reviewer is `OPEN_REVIEWER.cmd` / port 8774 (v2 stays on 8771). Support day labels shorter than five characters, independent flagged toggles, CNV outlines and source labels, moving/rotating individual fields, Move ONH, category changes, notes and individual/whole montage confirmation. Confirmation preserves flags; retries and JSON export must not silently discard pending edits.

Use `octa_reg_v3.review_server.analysis_inputs(folder)` for later analyses: whole-montage confirmation required, supported-only by default, flagged explicitly opt-in, excluded never included. ONH-adjusted effective matrices and notes travel with records. Release PNGs and coverage are not regenerated by later UI edits. Full selection details and measured limitations are in the release `REPORT.md` and `REVIEW_GUIDE.md`.
